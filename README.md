# Global-Olympics-Sports
Global Olympic Sports Performance Analysis is a Tableau-based data visualization project that explores historical Olympic data. It analyzes country-wise medal counts, athlete participation, gender representation, sports trends, and athlete demographics using interactive charts to uncover meaningful insights into Olympic performance.
